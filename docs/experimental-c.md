# C：允许轨迹分歧的长期实验

C 线与 A 线隔离。A 线保持严格等价；C 线每项实验只引入一个变量，记录首次分歧的位置和下游影响。本分支只记录研究路线和验收边界，具体实现放在独立实验分支中，不合并回 `main`。

## 推进和验收

每个实验先选定一个已验证的 A 提交作为对照，再只引入一种变量。先比相同输入下的局部输出，再比逐交互状态、动作和人口顺序，再比网络参数、Adam 状态和随机数流，最后记录轨迹首次分歧。

每次实验记录种子、模型、依赖、设备、输入规模、性能收益和分歧条件。速度变化和结果变化必须同时报告；能保持 A 语义的部分可以单独评审后移回 A。

## 候选与可能分歧

| 候选 | 首次分歧可能在哪里 | 需要记录 |
|---|---|---|
| 更深的 C++ 状态/事件引擎 | 对象别名、缓存失效、候选顺序或 RNG 接口 | 先尝试保持 A 语义；能保持的部分单独评审移回 A |
| SIMD/FMA/不同归约次序 | 浮点最后几位、零值/阈值、并列投票 | 最大/相对误差、第一次离散决策变化，不只看最终均值 |
| 世界 FP32/混合精度 | 路径归一化、评分、选人/淘汰边界 | 每阶段误差与轨迹分叉、内存/吞吐收益 |
| GPU 批量世界运算 | 同步批次代替顺序原地更新、设备舍入/RNG | 独立计算先尝试保序；依赖交互的部分不能伪装成等价并行 |
| 训练图编译或 C++ 训练调用 | 随机算子、浮点融合、优化器实现 | 核对原逐步更新；跨硬件随机序列不能假定一致 |
| 批训练/降低更新频率 | 下一次决策看到不同参数和 Adam 状态 | 明确是训练算法变化，不合并进 A 默认模式 |
| LLM 量化/小模型/缓存决策 | token、行动 JSON、奖励及火种/淘汰 | 文本和动作差异，不能只以生成速度验收 |
| ANE/Core ML 固定模型推理 | 转换算子、精度、CPU 回退 | 固定模型输出、设备分配、功耗和桌面响应性；非整世界/在线训练开关 |

## 与其他线的关系

- `main`：A 线，严格等价，v1.0.0 发布内容。
- `research/divergent-c`：C 线，本分支，只记录实验路线。
- C1/C2：批量评分与新生并行的子实验，若公开则在独立分支维护，不合并回 `main`。

## 执行

实验在可用的 CI 或专用机器上运行；具体命令和负载随实验分支给出，不在本分支内置新的运行入口。
