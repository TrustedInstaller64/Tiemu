# C：长期单世界性能实验

本分支由用户于2026-10-30授权建立，与 `codex/single-world-a` 隔离。A为主线；不建设多世界或批量实验能力。当前只有实验路线与差异边界，尚未改变运行算法。

## 推进和验收

每个实验先选定一个已验证的A提交作为对照，再只引入一种变量。先比相同输入下的局部输出，再比逐交互状态、动作和人口顺序，再比网络参数、Adam状态和随机数流，最后记录轨迹首次分歧。记录种子、模型、依赖、设备、输入规模、性能收益和分歧条件。C的速度变化与结果变化必须同时报告，不能自动合并回A。

## 候选顺序与可能分歧

| 候选 | 首次分歧可能在哪里 | 需要记录 |
|---|---|---|
| 更深的C++状态/事件引擎 | 对象别名、缓存失效、候选顺序或RNG接口 | 先尝试保持A语义；能保持的部分可单独评审移回A |
| SIMD/FMA/不同归约次序 | 浮点最后几位、零值/阈值、并列投票 | 最大/相对误差、第一次离散决策变化，不只最终均值 |
| 世界FP32/混合精度 | 路径归一化、评分、选人/淘汰边界 | 每阶段误差与轨迹分叉，内存/吞吐收益 |
| GPU批量世界运算 | 同步批次代替顺序原地更新、设备舍入/RNG | 独立计算先尝试保序；依赖交互不得伪装成等价并行 |
| 训练图编译或C++训练调用 | 随机算子、浮点融合、优化器实现 | 核对原逐步更新；跨硬件随机序列不能假定一致 |
| 批训练/降低更新频率 | 下一次决策看到不同参数和Adam状态 | 明确是训练算法变化，不合并进A默认模式 |
| LLM量化/小模型/缓存决策 | token、行动JSON、奖励及火种/淘汰 | 文本和动作差异，不能仅以生成速度验收 |
| ANE/Core ML固定模型推理 | 转换算子、精度、CPU回退 | 固定模型输出、设备分配、功耗和桌面响应性；非整世界/在线训练开关 |

## 执行限制

本机禁止高负荷运行、编译、测试、模型加载及Docker安装，直到用户解除限制。实验只在可用且获准的远端机器执行。不得把当前Mac注册成self-hosted runner绕过限制。普通CPU CI不构成CUDA/Metal/ANE真机验收。
