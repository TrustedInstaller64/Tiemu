## 选择的实现路线

纯 C++ 重写议会乘数的 dot/tanh 有归约与函数舍入风险；仅把 Python 列表改成矩阵不能接管状态准备。因此选用 **World 两阶段评分工作区**，将缓存收集/缺失缓存映射、非有限亲和度修复、boss 输入和最终批评分交给 C++，乘数先保留 NumPy 已有原生微核。批量 `vecdot`/`tanh` 只有在三平台严格探针和真实差分通过后才启用；不使用 GEMV 代替原逐行 dot，也不放宽断言。

World 的 live rows 可能已过期，且完整 sync 会拒绝评分本来应修复的非有限值。因此评分用独立 source 描述符，只复制当前被评分实体的必要字段，不同步整个世界，也不把上次交互的旧数值当成当前值。

`tiemu_world_scoring_prepare` 接收每行 titan 指针、旧路径缓存指针（可空）、boss 标志，以及 12×12 映射。先保留旧缓存，缺失时映射原始 titan，再将坏 titan 行修复为 ones。返回 World 持有的连续输入、旧路径、repair 位和非零 token；新路径和统计此时不可读取。

`tiemu_world_scoring_finish` 使用该 token、现有 evaluator、乘数和分布，复用现有线程池与评分核，返回新路径和四项统计。Python 在锁内提交独立缓存/修复数组与 float 标量。两次 C 调用之间不允许借用视图逃逸；数组 owner 与 evaluator/World 生命周期都由锁保护。token 单次消费，其他原生变更使它失效；失败不重跑部分执行的路径。评分准备标记 live 数值过期，下一次完整 sync 才能执行依赖 live rows 的阶段。

Python 新快路径只接受标准对象、原方法和无回调字段访问、独立 float64 行、标准 NumPy 错误模式及合法全局参数。错误模式、自定义方法/对象、重复引用、无效 evaluator、异常分布等走现有有序路径，保留原错误前缀。正常路径每批检查议会缓存一次，保留其公开字典和缓存的原语义。

首轮 Python 接入对所有输入行作一次批量有限值/范围检查：非有限值和极端值保留旧批路径，防止 `warnings` 将 NumPy 警告提升为异常时改变先前已写入的字段。C ABI 自身仍实现并验证先旧缓存后修复的规则。该保守检查有一次额外复制成本，计入完整阶段性能，不隐去。

## 后续两个有界迁移

黄金裔阶段只迁移当前角色/boss/score 的筛选与稳定排序计划，不上传亲和度。原人口顺序作为同分次序；Python 保留清旧身份、shuffle、分配方面和赋值顺序。非有限分数、无法精确表示的整数、重复实体、非标准 cap/访问器回退。

永劫每代建有序候选索引，保留轮回者兼黄金裔的重复权重、死者仍可能被抽中后跳过，以及单候选也消费随机数。普通交互只更新双方；每次轮回者实际交互之后重新扫描当前人口，覆盖网络/LLM/optimizer 回调对第三者或人口的修改，重建不再满足守卫时转回原选择器。原始循环次数与训练顺序保持不变，不枚举大量 PyTorch 私有 hook 来假设回调无副作用。
