## 范围

用户于 2026-11-03 要求继续 C 分支研究，先探索速度和偏差，再决定接受范围。本轮位于 `codex/c1-batched-scoring`，基于已验证 A2；原 C 路线分支保留，不向 A/main 合并。

唯一新增实验是将整批思潮乘数与评分准备接入独立 C++17 核心。世界仍用 float64，网络仍用 float32，不改交互、随机数消费和逐次训练更新的顺序。NumPy/BLAS 的两次 dot 和 NumPy tanh 换成 C++ 两次有序归约与 std::tanh，因此允许末位舍入差异；这些差异可能放大为评分排序、候选桶、淘汰、席位或训练轨迹差异。未使用 FP32 世界、fast-math、批交互或批训练。

开启方式是在原有命令追加 `--experimental-c-scoring --backend cpp`。默认关闭；自定义方法、席位容器等不符合实验约束时回退。C ABI 仍不依赖 pybind11。所有执行、编译、测试和测量位于 GitHub 托管机器，本机未运行项目或安装 Docker。

## 对照方法

- 原项目：`691c6e0023a83513ad3cd386cfee2198317104d3`，现场运行原 Python 源码。
- A2：`eca7377c6ee53ab1f57c32fd8227c31e0d73b1cb`，固定历史版本，不随其他任务推进的 A 分支移动。
- C1 关闭、C1 开启：同一个候选提交；关闭时的已检查末态必须与冻结 A2 完全相同。
- 同一 runner、同一依赖、CPU、固定 Python hash seed、PyTorch/BLAS/原生单线程。关闭 LLM、实际日志输出、显示和导出；保留原日志参数求值副作用。
- 三个有界场景：人类 1,000 人口×12 代、10,000×4 代、1,000×12 代含初始轮回者。计划每项检查种子 731、42、2026；万人场景实际仅完成前两个种子。这只是确定性敏感性检查，不是参数搜索或多世界产品功能。
- 性能采用 seed=731 的三次独立无观察进程，轮换配置顺序，取中位数。计时包含阶段的数据准备、C++ 调用、写回及首次线程池启动，排除初始化、模型加载、快照、淘汰名字整理和进程启动。不是完整世界或长期训练倍率。
- 如果轨迹已分叉，同配置的两个实现可能经历不同人口和有效交互，时间比仍是该配置的实测耗时比，但不能解释成完全相同工作量的底层执行效率比；须同时读对应人口和分歧记录。
- 观察进程在初态、每代交互后、每代生长后捕获快照；同模式同 seed 的观察/无观察末态摘要必须相同。首次分歧是**首次不同的检查点**，不等于已经定位首个因果交互。

## 如何理解“离散程度”

1. 数值误差：最大绝对误差、平均绝对误差、RMSE、相对 L2、超出历史参考容差的元素数。世界 `atol=rtol=1e-10`、网络/Adam `1e-6` 仅为诊断阈值，不是用户已接受的标准。
2. 离散状态：人口身份及顺序、淘汰、席位、黄金裔/实体标记、轮回者身份严格比较；RNG、网络哈希、缓存状态和观测路径分类单独报告。
3. 轨迹分叉后的分布：人口数量差、共同名字占比、路径分类总变差距离（TV，0 相同、1 完全分离）、席位 L1、评分均值/标准差/分位数、KS 与 Wasserstein 距离。KS/TV 不表示“多少百分比结果错误”。
4. 原版实体死亡后允许复用名字。因此首次离散或 RNG 分叉后，个体一一对应的数值比较停止；`numeric=null` 表示不能可靠对应，绝不表示零误差。共同名字只代表集合重叠，不代表血缘相同。
5. 同时报出 A2−原版、C1−原版、C1−A2，以分离此前迁移和本轮实验造成的差异。不把数值接近当作离散决策相同，也不把三种子短轨迹当作长期统计等价。

快照覆盖人口原字段与缓存、轮回者、蓝图、思潮、部分管理器字段、网络参数/Adam 和三 RNG；不是全部内部对象与别名的序列化。无机和永劫训练本轮没有新增性能结论，真实 LLM、GPU、ANE、能耗和用户 M1 不在本轮实测范围。

下一候选是批量新生实体数值初始化：保持逐个取名与 NumPy 正态抽样顺序，在一批内复用固定遗产向量，将初始裁剪、遗产加成、纯化、潮汐及归一化合成一次 C++ 调用。每个新实体仍须拥有独立数组，保留 `score=int(0)`、空路径缓存和追加顺序。否则共享行视图会触发交互引擎回退，或改变下一代的候选顺序。
